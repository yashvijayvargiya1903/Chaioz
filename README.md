# Chaioz — Premium Website Demo

A responsive premium one-page website concept for **Chaioz, North Adelaide**.

## What is included
- Editorial, premium visual direction using a deep chai-teal, warm cream, terracotta and muted gold palette
- Serif-led brand typography with clean sans-serif UI text
- Responsive mobile + desktop layout
- No horizontal page scrolling
- Mobile viewport tuned to avoid accidental tap-to-zoom and oversized form controls
- Working anchor navigation and mobile menu
- Menu modal with current public menu examples
- New-product launch modal
- Rewards information modal
- Order-online, directions, phone and Instagram links
- Restaurant/food imagery from publicly accessible Chaioz listings for this presentation demo
- Publicly documented September 2026 references to Chaioz's new matcha launches
